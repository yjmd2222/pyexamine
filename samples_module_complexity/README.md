# Module complexity sample projects (Python)

This archive contains several small Python projects intended for experiments on *module-level* coupling/cohesion.

- `projects/` contains the projects.
- `LABELS/` contains a label file and short notes.

## Running a project

Example:

```bash
cd projects/harbor_manifest
python -m harbor_manifest list
python -m harbor_manifest quote sample.json
python -m harbor_manifest route sample.json
```
